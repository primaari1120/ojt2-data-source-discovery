# OJT 2 — Smart Data Source Discovery

Repository ekspor paket pembaruan generalized field matching.

Paket `OJT2_Generalized_Matching_Update.zip` ditempatkan pada branch `exports/generalized-matching-update` saat ekspor selesai. Paket berisi source yang diperbarui, modul baru, kamus bilingual offline, lisensi dan sitasi, validator, README instalasi/pengujian, dan laporan hasil uji.

Paket tidak menyertakan SQLite history PIC, data produksi, credential, virtual environment, atau model embedding. Perubahan ini hanya mengekspor pekerjaan yang sudah selesai; tidak melakukan deployment aplikasi.
